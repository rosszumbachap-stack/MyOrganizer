# My Organizer // Helmet Terminal

Installable PWA version of My Organizer.

## GitHub Pages
1. Upload all files in this folder to the repository root.
2. In GitHub: Settings → Pages.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Open the GitHub Pages URL on Android in Chrome and choose **Add to Home screen** / **Install app**.

The app stores organizer data locally in the browser using localStorage.
